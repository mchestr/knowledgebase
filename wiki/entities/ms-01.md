# Minisforum MS-01

## Summary

The mini PC model of all three [[home-cluster]] nodes ([[home-cluster-readme]]).

## Facts

| Node | LAN IP | Ring IP |
| --- | --- | --- |
| m0 | 10.0.40.10 | 169.254.255.10 |
| m1 | 10.0.40.11 | 169.254.255.11 |
| m2 | 10.0.40.12 | 169.254.255.12 |

- CPU i9-13900H, 96GB RAM, 1TB OS disk, 2TB data disk ([[home-cluster-node-management]]).
- Each node has a 10Gb LACP link to the USW-Pro-Aggregation switch. Two Thunderbolt 4 ports connect it to the other two nodes ([[home-cluster-networking]], [[thunderbolt-ring-network]]).
- PiKVM V4 Mini gives remote console access ([[home-cluster-networking]]).

## Secure Boot setup

Secure Boot is hard to enable on the MS-01 ([[home-cluster-bootstrap]]):

1. Boot to the BIOS.
2. Set `Security` > `Secure Boot` to `custom`.
3. Open `Key Management`.
4. Set `Factory Key Provision` to `disabled`.
5. Click `Reset To Setup Mode`. Click `cancel` when it asks to save without exit.
6. Save and reset.
7. Mount the Talos image, reboot, and select `Enroll secure boot keys: auto`.

Key violation errors at boot mean that step 4 did not wipe the factory keys.
