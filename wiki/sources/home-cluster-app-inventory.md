# home-cluster app inventory (generated)

## Summary

A table of the 96 Flux Kustomizations under `kubernetes/apps` at commit `924c31d`, made with `yq` from the manifests. It lists the namespace, chart, main images, gateway, components, `dependsOn` and NetworkPolicy coverage of each one. The organized view is [[app-inventory]].

## Key points

- 96 Kustomizations in 17 namespaces. Largest: `media` and `default`.
- 12 Kustomizations route to `envoy-external`. One of them is the `envoy` gateway itself.
- NetworkPolicy coverage for external apps is in [[security-posture]].
- Removed since `e36a8c8`: `jellyfin`, `jellyplex-watched` and `windmill` (98 became 96 with `silo` added).
- Added since `e36a8c8`: `silo` (internal gateway, `cnpg` and `dragonfly`, Intel GPU plugin, `silo-server:build-2069`).
- `dependsOn` changes: `atuin`, `grafana` and `grafana-instance` now depend on `onepassword-store`, and `victoria-logs` depends on `rook-ceph-cluster`.
- The `onepassword` Connect images moved to `ghcr.io/1password`.
- Most other changes are image version bumps (for example `home-assistant` 2026.11.0, `radarr` 7.0.1, `prowlarr` 3.0.0, `unpackerr` v1.0.1, `plex-manager` 0.11.0).

## Data and quotes

Method limits:
- "Gateway" counts only `parentRefs` that name an `envoy-*` gateway.
- "NetworkPolicy" is a text match on `owning-gateway-name` and `kube-apiserver` in the app path. Policies added by a component (for example `dragonfly`) are not counted.
- A first version of the generator missed policies written with the app-template `networkpolicies:` key. The raw file is the corrected version.

Version `924c31d` was generated on 2026-11-08. Version `e36a8c8` listed 98 Kustomizations.
